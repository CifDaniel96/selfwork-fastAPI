# Movie Catalog API

Movie Catalog API è un progetto FastAPI realizzato come selfwork della specializzazione **Agentic AI & Python**.

Il progetto replica i concetti affrontati nella lezione FastAPI attraverso una semplice API dedicata a un catalogo di film.

## Funzionalità

- endpoint GET
- path parameters
- query parameters
- validazione dei parametri
- request body con Pydantic
- endpoint POST e PUT
- documentazione automatica Swagger

## Tecnologie utilizzate

- Python
- FastAPI
- Uvicorn
- Pydantic
- Poetry
